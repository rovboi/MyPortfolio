# Fullstack Python & Telegram Developer Portfolio

Привет! Я Fullstack-разработчик. Специализируюсь на создании сложных Telegram-ботов, AI-ассистентов (RAG) и полноценных веб-приложений внутри Telegram (Mini Apps). Закрываю полный цикл: от проектирования БД и бэкенда до адаптивного фронтенда и деплоя.

## 🛠 Технологический стек
* **Backend:** Python (aiogram 3, FastAPI), Node.js, REST API, Webhooks
* **Frontend (TMA / Admin):** React, TypeScript, Tailwind CSS, Telegram WebApp API
* **AI & Data:** RAG (LangChain / LlamaIndex, векторные БД), OpenAI API
* **Базы данных и инфраструктура:** PostgreSQL, Redis, SQLAlchemy, Docker, Linux (VPS)

## 🚀 Проекты

### 1. RAGAssistant — AI-ассистент с базой знаний
Умный бот, который отвечает на вопросы пользователей строго по загруженной документации компании, исключая галлюцинации нейросети.
* **Что реализовано:** парсинг и векторизация документов, поиск релевантного контекста, сохранение истории диалога в БД.
* **Стек:** Python, [aiogram / FastAPI], [LangChain / OpenAI API], [PostgreSQL / ChromaDB / Qdrant].
* **Код:** [Перейти в папку проекта](./FirstProject/RAGAssistant)

### 2. BotWithPayment — Бот с приемом платежей и подписками
Коммерческий бот для монетизации контента или услуг с автоматической выдачей доступа.
* **Что реализовано:** интеграция платежных шлюзов, система рекуррентных платежей/подписок, веб-админка для управления пользователями и аналитикой.
* **Стек:** Python, React, TypeScript, Tailwind CSS, PostgreSQL, [ЮKassa / CryptoBot / Telegram Stars].
* **Код:** [Перейти в папку проекта](./SecondProject/BotWithPayment)

### 3. HybridBot — Гибридная система (Бот + WebApp)
Решение, объединяющее классический интерфейс команд бота и полноценное веб-приложение (Telegram Mini App) для сложного UX.
* **Что реализовано:** бесшовная авторизация через `initData` Telegram, интерактивный интерфейс на React, синхронизация состояний между ботом и веб-частью.
* **Стек:** Python / Node.js, React, TypeScript, Tailwind CSS, Redis.
* **Код:** [Перейти в папку проекта](./ThirdProject/HybridBot)
